# User Management Guide

คู่มือการจัดการผู้ใช้และสิทธิ์การเข้าถึง

## ภาพรวม

ระบบ OCR มีระบบการจัดการผู้ใช้และสิทธิ์การเข้าถึงที่ปลอดภัย โดยแบ่งสิทธิ์ออกเป็น 2 ระดับ: **Admin** และ **User**

## ระดับสิทธิ์ผู้ใช้

### 🔑 Administrator (Admin)
**สิทธิ์การเข้าถึง:**
- ✅ ดูและแก้ไขการตั้งค่า OCR
- ✅ ตั้งค่าเครือข่าย (IP, Gateway, DNS)
- ✅ จัดการผู้ใช้ (เพิ่ม/แก้ไข/ลบ)
- ✅ เข้าถึงการตั้งค่าระบบทั้งหมด
- ✅ ดู System logs และ monitoring

### 👤 Regular User (User)
**สิทธิ์การเข้าถึง:**
- ✅ ดูการตั้งค่า OCR (Read-only)
- ✅ ดู Live preview และผลลัพธ์ OCR
- ✅ ดู System logs
- ❌ แก้ไขการตั้งค่าใดๆ
- ❌ เข้าถึงการตั้งค่าเครือข่าย
- ❌ จัดการผู้ใช้อื่น

## การใช้งานสำหรับ Admin

### เข้าสู่ระบบ
```
Username: Admin
Password: Abc123**
```

### การจัดการผู้ใช้

#### 1. ดูรายชื่อผู้ใช้
1. คลิกไอคอน 👥 ใน sidebar
2. หน้าต่างจัดการผู้ใช้จะเปิดขึ้น
3. ดูรายชื่อผู้ใช้ทั้งหมดในตาราง

#### 2. เพิ่มผู้ใช้ใหม่
1. คลิก "➕ เพิ่มผู้ใช้ใหม่"
2. กรอกข้อมูล:
   - **ชื่อผู้ใช้**: ไม่ซ้ำกับที่มีอยู่
   - **รหัสผ่าน**: แนะนำให้ใช้รหัสผ่านที่แข็งแรง
   - **บทบาท**: เลือก admin หรือ user
3. คลิก "บันทึก"

#### 3. แก้ไขผู้ใช้
1. คลิก "✏️ แก้ไข" ในแถวของผู้ใช้ที่ต้องการ
2. แก้ไขข้อมูลที่ต้องการเปลี่ยน
3. คลิก "บันทึก"

#### 4. ลบผู้ใช้
1. คลิก "🗑️ ลบ" ในแถวของผู้ใช้ที่ต้องการลบ
2. ยืนยันการลบ
3. ผู้ใช้จะถูกลบออกจากระบบ

## การใช้งานสำหรับ User

### เข้าสู่ระบบ
```
Username: STA-SK
Password: Abc123**
```

### สิ่งที่ User จะเห็น
1. **Form การตั้งค่า**: จะถูก disable และแสดงเครื่องหมาย 🔒
2. **Sidebar**: ปุ่มจะถูก lock และแสดงไอคอนกุญแจ
3. **แจ้งเตือน**: เมื่อพยายามเข้าถึงฟังก์ชันที่ไม่มีสิทธิ์

### การทำงานในโหมด Read-only
- สามารถดูการตั้งค่าปัจจุบันได้
- สามารถดู live preview ของกล้องได้
- สามารถดูผลลัพธ์ OCR ได้
- สามารถดู system logs ได้

## การกำหนดค่าผู้ใช้

### ไฟล์การตั้งค่า: `config/users.json`

```json
{
  "users": [
    {
      "username": "Admin",
      "password": "Abc123**",
      "role": "admin",
      "created": "2025-10-10T00:00:00.000Z",
      "lastLogin": null,
      "active": true
    },
    {
      "username": "STA-SK",
      "password": "Abc123**", 
      "role": "user",
      "created": "2025-10-10T00:00:00.000Z",
      "lastLogin": null,
      "active": true
    }
  ],
  "settings": {
    "sessionTimeout": 86400,
    "maxLoginAttempts": 5,
    "lockoutDuration": 1800
  }
}
```

### คำอธิบายฟิลด์
- **username**: ชื่อผู้ใช้ (ต้องไม่ซ้ำ)
- **password**: รหัสผ่าน (ในอนาคตจะเข้ารหัส)
- **role**: บทบาท (admin หรือ user)
- **created**: วันที่สร้างบัญชี
- **lastLogin**: การเข้าสู่ระบบครั้งล่าสุด
- **active**: สถานะการใช้งาน (true/false)

### การตั้งค่าระบบ
- **sessionTimeout**: ระยะเวลา session หมดอายุ (วินาที)
- **maxLoginAttempts**: จำนวนครั้งสูงสุดที่พยายามเข้าสู่ระบบ
- **lockoutDuration**: ระยะเวลา lock บัญชี (วินาที)

## ระบบความปลอดภัย

### Session Management
- Session จะหมดอายุหลังจาก 24 ชั่วโมง
- การออกจากระบบจะลบ session ทันที
- ตรวจสอบสิทธิ์ในทุก API call

### การป้องกัน
- ป้องกัน brute force attack
- Validation ข้อมูลผู้ใช้
- Authorization ในทุกฟังก์ชัน

## ตัวอย่างการใช้งาน

### สถานการณ์: เพิ่มผู้ใช้ใหม่สำหรับช่างเทคนิค
1. Admin เข้าสู่ระบบ
2. เปิดหน้าจัดการผู้ใช้
3. เพิ่มผู้ใช้ใหม่:
   ```
   Username: TECH-01
   Password: Tech@123
   Role: user
   ```
4. บันทึกข้อมูล
5. แจ้งข้อมูลการเข้าสู่ระบบให้ช่าง

### สถานการณ์: ปรับสิทธิ์ผู้ใช้เป็น Admin
1. Admin เข้าสู่ระบบ
2. แก้ไขผู้ใช้ที่ต้องการ
3. เปลี่ยน role จาก "user" เป็น "admin"
4. บันทึกการเปลี่ยนแปลง

## การแก้ไขปัญหา

### ปัญหา: ลืมรหัสผ่าน Admin
**วิธีแก้:**
1. แก้ไขไฟล์ `config/users.json` โดยตรง
2. เปลี่ยนรหัสผ่านในฟิลด์ "password"
3. รีสตาร์ทเซิร์ฟเวอร์

### ปัญหา: ผู้ใช้ถูก lock
**วิธีแก้:**
1. ตรวจสอบ maxLoginAttempts ใน settings
2. รอให้ lockoutDuration หมดเวลา
3. หรือรีสตาร์ทเซิร์ฟเวอร์

### ปัญหา: Session หมดอายุบ่อย
**วิธีแก้:**
1. เพิ่มค่า sessionTimeout ใน settings
2. หน่วยเป็นวินาที (86400 = 24 ชั่วโมง)

## Best Practices

### สำหรับ Admin
- ใช้รหัสผ่านที่แข็งแรง
- เปลี่ยนรหัสผ่านเป็นระยะ
- ตรวจสอบการเข้าสู่ระบบของผู้ใช้
- สำรองไฟล์ users.json เป็นระยะ

### สำหรับ User
- ไม่แชร์รหัสผ่านกับผู้อื่น
- ออกจากระบบเมื่อใช้งานเสร็จ
- แจ้ง Admin หากพบปัญหา

### สำหรับระบบ
- ตั้งค่า sessionTimeout ให้เหมาสม
- Monitor การเข้าสู่ระบบ
- อัปเดตรหัสผ่านเริ่มต้นก่อนใช้งานจริง
