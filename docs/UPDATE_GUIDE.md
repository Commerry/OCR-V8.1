# อัพเดตโปรแกรม OCR บนกล้อง CM4

สำหรับเครื่องที่มีโปรแกรมเก่าอยู่แล้ว — **คำสั่งเดียวจบ** สคริปต์จัดการตั้งเวลา → proxy → ดาวน์โหลดโค้ดใหม่ → ติดตั้ง → ตั้ง startup ให้เอง
(การลบโปรแกรมเก่าทำเองตามสะดวก — สคริปต์ไม่แตะโฟลเดอร์เก่า)

---

## วิธีใช้

```bash
curl -x http://10.201.0.54:8080 -sL -o /tmp/update.sh https://raw.githubusercontent.com/Commerry/OCR-V8.1/main/update.sh
bash /tmp/update.sh "2026-08-06 21:30:00"
```

**แก้เวลาในเครื่องหมายคำพูดเป็นเวลาจริงขณะรันทุกครั้ง** (`"ปี-เดือน-วัน ชม:นาที:วินาที"`)
ถ้าไม่ใส่เวลา สคริปต์จะไม่ทำงานและแสดงตัวอย่างให้

> เครื่องที่ออกเน็ตตรงได้ (ไม่ต้องผ่าน proxy) ตัด `-x http://10.201.0.54:8080` ออกจากคำสั่ง curl

---

## สคริปต์ทำอะไรบ้าง (อัตโนมัติทั้งหมด ไม่มีคำถามระหว่างทาง)

| ขั้น | ทำอะไร |
|---|---|
| 0 | **ตั้งนาฬิกาเครื่อง** ตามเวลาที่ใส่มา (นาฬิกาผิดทำ TLS/apt พัง) |
| 1 | **เซ็ต proxy** `10.201.0.54:8080` ให้ npm / pip / git / apt / env |
| 2 | **ดาวน์โหลดโค้ดใหม่** จาก GitHub ไปที่ `~/Desktop/OCR-V8.1` (มีอยู่แล้ว = อัพเดตทับ, ยังไม่มี = clone ใหม่) |
| 3 | ติดตั้ง Node ถ้ายังไม่มีหรือเก่าเกิน (ใช้ tarball ที่มากับโค้ด) |
| 4 | **เคลียร์ pm2 startup เดิม** (ไม่สนว่าโปรแกรมเก่าชื่ออะไร อยู่ path ไหน) |
| 5 | ติดตั้ง redis (ถ้ายังไม่มี) + npm dependencies (สลับ npm 11 → 10 เองถ้าจำเป็น) |
| 6 | ติดตั้ง python packages + สร้าง `.env` |
| 7 | `pm2 start` + ตั้ง **startup ใหม่** (auto-start ตอนบูต) |
| จบ | ตรวจสอบตัวเองแล้วรายงานผล |

## ผลที่ต้องเห็นตอนจบ

```
UPDATE COMPLETE - ready to use
  http://<IP กล้อง>:64010
```

เปิดเบราว์เซอร์ตาม URL → login `Admin` / `Abc123**`

ถ้าขึ้น `UPDATE FAILED` → ดู error ด้วย `pm2 logs ocr --lines 30`
