# Network Configuration Guide

คู่มือการตั้งค่าเครือข่ายสำหรับระบบ OCR

## ภาพรวม

ระบบ OCR มีความสามารถในการจัดการการตั้งค่าเครือข่ายผ่านเว็บ interface ที่ทันสมัย โดยสามารถเปลี่ยนแปลงการตั้งค่า IP ได้แบบ real-time

## คุณสมบัติ

### 🔧 โหมดการตั้งค่า
- **DHCP**: รับ IP อัตโนมัติจาก DHCP Server
- **Static IP**: กำหนด IP แบบคงที่

### 🛡️ ระบบความปลอดภัย
- เฉพาะ Admin เท่านั้นที่สามารถเปลี่ยนแปลงการตั้งค่าได้
- มีระบบสำรองการตั้งค่าเดิมอัตโนมัติ
- สามารถคืนค่าการตั้งค่าเดิมได้หากเกิดปัญหา

### ⚡ การทำงานแบบ Real-time
- การเปลี่ยนแปลงมีผลทันที
- แสดงสถานะการเชื่อมต่อ
- ทดสอบการเชื่อมต่ออัตโนมัติ

## วิธีการใช้งาน

### 1. เข้าสู่ระบบ
```
Username: Admin
Password: Abc123**
```

### 2. เปิดหน้าต่างการตั้งค่าเครือข่าย
- คลิกที่ไอคอน 🌐 ใน sidebar ด้านซ้าย
- หน้าต่าง modal จะเปิดขึ้นมา

### 3. การตั้งค่า DHCP
1. เลือก "DHCP (อัตโนมัติ)" จาก dropdown
2. คลิก "💾 บันทึก"
3. ระบบจะเปลี่ยนเป็นโหมด DHCP และรับ IP อัตโนมัติ

### 4. การตั้งค่า Static IP
1. เลือก "Static IP (กำหนดเอง)" จาก dropdown
2. กรอกข้อมูลตามต้องการ:
   - **IP Address**: เช่น `192.168.1.100`
   - **Subnet Mask**: เช่น `255.255.255.0`
   - **Gateway**: เช่น `192.168.1.1`
   - **DNS Server**: เช่น `8.8.8.8, 8.8.4.4`
3. คลิก "💾 บันทึก"

## ตัวอย่างการตั้งค่า

### การตั้งค่าสำหรับ Local Network
```
IP Address: 192.168.1.100
Subnet Mask: 255.255.255.0
Gateway: 192.168.1.1
DNS: 8.8.8.8, 8.8.4.4
```

### การตั้งค่าสำหรับ Office Network
```
IP Address: 10.0.1.100
Subnet Mask: 255.255.255.0
Gateway: 10.0.1.1
DNS: 10.0.1.1, 8.8.8.8
```

## การแก้ไขปัญหา

### ปัญหา: ไม่สามารถเชื่อมต่ออินเทอร์เน็ตได้หลังเปลี่ยน IP
**วิธีแก้:**
1. ตรวจสอบ Gateway และ DNS ว่าถูกต้อง
2. ลองเปลี่ยนกลับเป็น DHCP ชั่วคราว
3. ติดต่อผู้ดูแลเครือข่าย

### ปัญหา: การตั้งค่าไม่มีผล
**วิธีแก้:**
1. รอสักครู่ให้ระบบประมวลผล
2. รีสตาร์ทระบบเครือข่าย: `sudo systemctl restart networking`
3. ตรวจสอบ log ในระบบ

### ปัญหา: เข้าเว็บไซต์ไม่ได้หลังเปลี่ยน IP
**วิธีแก้:**
1. ใช้ IP ใหม่ในการเข้าเว็บไซต์
2. ตัวอย่าง: `http://192.168.1.100:64010`
3. อัปเดต bookmark ให้ตรงกับ IP ใหม่

## คำสั่ง Command Line สำหรับการตรวจสอบ

### ดู IP ปัจจุบัน
```bash
ip addr show eth0
```

### ดู Gateway
```bash
ip route show default
```

### ดู DNS
```bash
cat /etc/resolv.conf
```

### ทดสอบการเชื่อมต่อ
```bash
ping google.com
ping 8.8.8.8
```

### ดูสถานะ Network Interface
```bash
sudo systemctl status networking
```

## ข้อควรระวัง

⚠️ **สำคัญ**: หากคุณเปลี่ยน IP แล้วไม่สามารถเข้าถึงระบบได้ ให้:
1. เชื่อมต่อจอและแป้นพิมพ์โดยตรง
2. ใช้คำสั่ง `sudo netplan apply` เพื่อใช้การตั้งค่าใหม่
3. หรือใช้ `sudo dhclient eth0` เพื่อขอ IP ใหม่จาก DHCP

💡 **คำแนะนำ**: สำรองการตั้งค่าเครือข่ายเดิมก่อนเปลี่ยนแปลง

## การสำรองและคืนค่า

ระบบจะสำรองการตั้งค่าเครือข่ายอัตโนมัติที่:
```
/etc/netplan/backup/network-[timestamp].yaml
```

หากต้องการคืนค่า:
```bash
sudo cp /etc/netplan/backup/network-[timestamp].yaml /etc/netplan/01-network-manager-all.yaml
sudo netplan apply
```
